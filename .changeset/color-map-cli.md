Add `color-map-cli`, the `color-map` command for agents: `convert`, `mix`, `contrast`, `find-contrast`, `scale`, `palette`, `harmony`, `export` and `schema`. Output is TOON by default (`--format json` for JSON), errors are coded, and WCAG 2 is the contrast measure. It ships JSON Schemas for every command's options, an `llms.txt`, and a `color-map` agent skill as a plugin for Claude Code, Cursor, Codex and Copilot CLI.
